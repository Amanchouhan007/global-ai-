# GlobalHealthAI

A physician-curated, AI-powered symptom education and clinical guidance platform with 1,000 clinically reviewed cards from 38 years of experience.

## Project Structure
- `frontend/`: React + Vite + Tailwind CSS frontend application.

## Getting Started

### Local Development
```bash
cd frontend
npm install
npm run dev
```

### Production Build
```bash
cd frontend
npm run build
```

The compiled output will be generated in `frontend/dist`.
